게임 규칙:
간단 - 
원신 게임 안에서 모자를 이용해(만약 없다면 봇에서?) 숫자를 뽑아서
낮은 사람 2명은 랜덤으로 지정된 캐릭터로 숫자 높은 사람 2명은 원하는거 골라서
캐릭터 선택이 전부 끝나면 그 파티로 랜덤으로 보스 뽑아서 그걸 잡으러 가는 게임.
세부 -
숫자 똑같이 나오면 리롤.
만약 랜덤으로 나온 캐릭이 없으면 다시 랜덤으로 지정.
동일한 사람이 직전에 나온 캐릭터 연속으로 사용 불가. 만약 랜덤으로 뽑혔다면 가능.
보스가 정해지면 캐릭터 못바꾸고, 필드보스시 5성은 재참전 불가, 4성은 재참전 가능.(주보는 구조상 리스폰 불가)
모자에서 나온 숫자 중에 01은 베넷 제외하고 4성 중에서 선택, 20은 보스 고른 이후에 같은 타입 안에서 원하는거 고르기 가능.
기권 가능. 음식, 도핑 가능. 
에일로이, 여행자, 별인형은 4성취급.

구조: 
config.json에 설정
data에 저장된 json 구조:
    title: 원신 팬덤 위키 분류 내에 있는 영어 이름
    weight: 랜덤 가중치(1이 기본)
    ko_text: 위키 내에 있는 크롤링된 한국어 번역
    ko: 수동으로 검수한 번역
현재 크롤러, 번역 스크립트는 crawler.py에 합쳐져 있음. (기존 스크립트는 test에 예비용으로 남겨둠)
test - 테스트 및 예비용 스크립트 저장 (수동번역, 가중치값 추가 후 랜덤 뽑기 테스트, 더 랜덤한 함수(시스템 랜덤) 테스트)
