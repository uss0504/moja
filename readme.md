# 원신 모자 게임

원신의 캐릭터와 보스를 이용해 진행하는 **랜덤 파티 구성 게임**입니다.

플레이어가 모자[^1]에서 숫자를 뽑고, 나온 숫자에 따라 캐릭터를 선택한 뒤 랜덤으로 결정된 보스를 처치합니다.

[^1]: 인게임 아이템 이름: 운명 계시기, 리넷 초대이벤트 초반에서 획득 가능

---

## 🎮 게임 규칙

### 기본 진행

1. 각 플레이어가 모자[^1]에서 숫자를 뽑습니다.
   * 모자가 없다면 Discord 봇의 랜덤 숫자 기능을 사용할 수 있습니다.
   * 숫자는 `1~20` 중 하나입니다.
2. 숫자가 같은 플레이어가 있다면 해당 플레이어들은 **리롤**합니다.
3. 숫자가 낮은 2명은 **랜덤으로 지정된 캐릭터**를 사용합니다.
4. 숫자가 높은 2명은 **원하는 캐릭터를 직접 선택**합니다.
5. 모든 캐릭터 선택이 끝나면 보스를 랜덤으로 결정합니다.
6. 결정된 파티로 해당 보스를 처치합니다.

### 3,4: 캐릭터 선택 규칙

* 랜덤으로 지정된 캐릭터를 현재 보유하지 않는 경우 다시 랜덤으로 지정합니다.
* 동일한 사람이 **직전에 사용한 캐릭터를 연속으로 사용할 수 없습니다.**

  * 단, 랜덤 추첨으로 다시 같은 캐릭터가 나온 경우에는 사용할 수 있습니다.
* 캐릭터 선택이 끝나고 보스가 결정되면 **캐릭터를 변경할 수 없습니다.**
* `에일로이`, `여행자`, `별인형`은 **4성 캐릭터로 취급**합니다.

### 특수 숫자

#### `01`

`01`이 나온 플레이어는 다음 조건으로 캐릭터를 선택합니다.

* 베넷을 제외한 4성 캐릭터 중 선택
* 5성 캐릭터는 선택할 수 없음

#### `20`

`20`이 나온 플레이어는 다음과 같이 진행합니다.

* 보스가 결정된 후
* 해당 보스와 **같은 타입(주보, 필보)**의 보스 중 원하는 보스를 선택할 수 있음

### 보스 규칙

***보스가 결정된 이후에는 캐릭터를 변경할 수 없습니다.***

**필드 보스**

* 5성 캐릭터: 해당 게임에서 재참전 불가
* 4성 캐릭터: 재참전 가능

**주간 보스**

* 구조상 리스폰이 불가능히므로 별도의 재참전 규칙을 적용하지 않습니다.

### 기타

* 기권 가능
* 음식 사용 가능
* 각종 도핑 가능

# 📁 코드 구조

```text
.
├── config.json
├── crawler.py
├── data/
│   └── *.json
├── test/
│   └── 이전 버전 코드, 테스트용 코드.py
├── .env
├── requirements.txt
├── random_*.py
├── discord_*.py
└── README.md
```

## `config.json`

크롤러에 쓰이는 설정입니다.

## `.env`

Discord 봇 토큰은 `.env`에 저장합니다.

```env
DISCORD_TOKEN=your_token_here
```

## `data/`

원신 캐릭터 및 보스 등의 데이터를 JSON 형식으로 저장합니다.

기본적인 데이터 구조는 다음과 같습니다.

```json
{
    "title": "English Name",
    "weight": 1,
    "ko_text": "크롤링된 한국어 번역",
    "ko": "수동으로 검수한 한국어 번역"
}
```

### 데이터 항목

| 항목        | 설명                      |
| --------- | ----------------------- |
| `title`   | 원신 팬덤 위키 분류에 사용되는 영어 이름 |
| `weight`  | 랜덤 추첨 가중치               |
| `ko_text` | 위키에서 크롤링한 한국어 데이터        |
| `ko`      | 수동으로 검수한 한국어 번역         |

캐릭터 이름을 표시할 때는 다음 우선순위를 사용합니다.

```text
수동 번역(ko)
    ↓
자동 번역(ko_text)
    ↓
영어 이름(title)
```

# 🕷️ 데이터 크롤러

현재 데이터 크롤러와 번역 관련 스크립트는 `crawler.py`에 통합되어 있습니다.

기존에 사용하던 테스트 및 예비 스크립트는 `test/`에 보관하고 있습니다.

데이터 업데이트 과정에서 다음 사항을 고려해야합니다.

* 기존 캐릭터/보스 데이터 유지
* 수동 번역 유지
* 기존 가중치 유지
* 새로운 데이터 추가
* 삭제된 데이터 처리
* 중복 `pageid` 처리

업데이트 스크립트가 데이터를 갱신하더라도 기존에 사람이 직접 수정한 `ko`와 `weight`가 가능한 한 유지되도록 구성되어 있습니다.

# 🎲 랜덤 시스템

기본 가중치는 `1`입니다.

소수점 가중치도 사용할 수 있으며, Secret/System 계열 랜덤을 사용할 경우 최대 `10^-6` 자릿수의 가중치를 사용가능합니다.

현재 테스트한 랜덤 방식:

* 기본 Python 랜덤
* 시스템 랜덤
* Secure 랜덤 (*사용중)

향후 디버그, 관리자 옵션을 통해 랜덤 방식을 선택할 수 있도록 할 예정입니다.

# ⚖️ 밸런스

## 보스 가중치

*구버전* 기존 비율:

```text
필드 보스 : 주간 보스 = 8 : 2
```

*구버전* 지방 전설까지 포함하는 경우:

```text
필드 보스 : 주간 보스 : 지방 전설 = 7 : 2 : 1
```

**현재**는 대부분 이런 비율로 지정되어있습니다.

```text
필드 보스 : 주간 보스 ≈ 1 : 0.8
```


### 가중치 조정 기준

향후 다음 요소를 반영할 예정입니다.

* 신규 보스 추가 시 가중치 조정
* 워프 포인트에서 먼 보스의 가중치 감소
* 관리자 명령어를 통한 수동 가중치 조정

## 캐릭터 밸런스

초기에는 4성/5성 등장 비율을 대략 `4:3` 정도로 맞추는 것을 고려했습니다.

하지만 현재는 캐릭터별 가중치를 이용해 어느 정도 공평하게 등장하도록 조정하고 있기 때문에 별도의 성급 비율 제한은 필요하지 않을 것으로 판단하고 있습니다.

### 원소별 가중치

* 바위
* 바람

캐릭터는 일부를 제외하고 일괄적으로 등장 확률을 낮추는 방향으로 조정되어있습니다.
