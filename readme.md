# 원신 모자 게임

원신의 캐릭터와 보스를 이용해 진행하는 **랜덤 파티 구성 게임**입니다.

플레이어가 모자[^1]에서 숫자를 뽑고, 나온 숫자에 따라 캐릭터를 선택한 뒤 랜덤으로 결정된 보스를 처치합니다.

[^1]: 인게임 아이템 이름: '운명 계시기', 리넷 초대이벤트 초반에서 획득 가능

---

## 🎮 게임 규칙

### 기본 진행

1. 각 플레이어가 모자[^1]에서 숫자를 뽑습니다.
   * 모자가 없다면 Discord 봇의 랜덤 숫자 기능을 사용할 수 있습니다.
   * 숫자는 `1~20` 중 하나입니다.
2. 숫자가 같은 플레이어가 있다면 해당 플레이어들은 **리롤**합니다.
3. 숫자가 낮은 2명은 **랜덤으로 지정된 캐릭터**를 사용합니다.
4. 숫자가 높은 2명은 **원하는 캐릭터를 직접 선택**합니다.
5. 모든 캐릭터 선택이 끝나면 보스를 랜덤으로 결정합니다.
6. 결정된 파티로 해당 보스를 처치합니다.

### 3,4: 캐릭터 선택 규칙

* 랜덤으로 지정된 캐릭터를 현재 보유하지 않는 경우 다시 랜덤으로 지정합니다.
* 동일한 사람이 **직전에 사용한 캐릭터를 연속으로 사용할 수 없습니다.**

  * 단, 랜덤 추첨으로 다시 같은 캐릭터가 나온 경우에는 사용할 수 있습니다.
* 캐릭터 선택이 끝나고 보스가 결정되면 **캐릭터를 변경할 수 없습니다.**
* `에일로이`, `여행자`, `별인형`은 **4성 캐릭터로 취급**합니다.

### 특수 숫자

#### `20`

`20`이 나온 플레이어는 다음과 같은 권한이 있습니다.

* 보스가 결정된 후
* 해당 보스와 **같은 타입(주보, 필보)**의 보스 중 원하는 보스를 선택할 수 있음

#### `01`

`01`이 나온 플레이어는 다음 권한이 있습니다.

* 베넷을 제외한 4성 캐릭터 중 선택
* 5성 캐릭터는 선택할 수 없음

### 보스 규칙

***보스가 결정된 이후에는 캐릭터를 변경할 수 없습니다.***

**필드 보스**

* 5성 캐릭터: 해당 게임에서 재참전 불가
* 4성 캐릭터: 재참전 가능

**주간 보스**

* 구조상 리스폰이 불가능히므로 별도의 재참전 규칙을 적용하지 않습니다.

### 기타

* 기권 가능
* 음식 사용 가능
* 각종 도핑 가능

## `config.json`

크롤러와 보스 추첨에 쓰이는 설정입니다.

`recent_boss_weight_multipliers`는 최근에 나온 보스부터 순서대로 적용하는 가중치 배율입니다.
기본값 `[0.05, 0.12, 0.20, 0.40]`은 직전 보스의 기존 가중치를 5%로, 그 이전 보스는 12%, 20%, 40%로 낮춥니다.
목록에 없는 과거 보스는 기존 `weight`를 그대로 사용합니다. 각 값은 0 초과 1 이하로 설정해야 하며,
목록을 수정해 적용할 추첨 횟수와 배율을 바꿀 수 있습니다.

최근 추첨 기록은 `data/boss_history.json`에 저장됩니다. 이 파일은 자동 생성되며 Git에는 포함되지 않습니다.

## Discord 봇 서버·채널 설정

`discord_bot.py`의 `CONTROL_CHANNEL_ID`, `CONTROL_MESSAGE_ID` 값을 사용해도 됩니다.
여러 채널을 설정하려면 `config.json`의 `discord.control_channels` 배열에 채널별 설정을 추가합니다.
배열이 비어 있으면 기존 상수 설정을 사용하고, 배열에 항목이 있으면 해당 목록이 기존 상수 대신 사용됩니다.

```json
"discord": {
  "control_channels": [
    {
      "channel_id": 123456789012345678,
      "message_id": 234567890123456789
    },
    {
      "channel_id": 345678901234567890,
      "message_id": null
    }
  ]
}
```

`channel_id`는 제어 메시지를 둘 텍스트 채널 ID입니다. `message_id`에 기존 메시지 ID를 넣으면 그 메시지에 달린 반응으로 명령을 실행하고, `null`이면 봇이 시작될 때 해당 채널에 제어 메시지를 생성합니다. `null`로 둔 항목은 봇을 재시작할 때마다 새 제어 메시지를 생성합니다. 서버 개발자 모드를 켜면 채널과 메시지 ID를 복사할 수 있습니다.
각 서버에 봇을 초대해야 하며, 지정 채널에서 메시지 보기·보내기·메시지 기록 보기·반응 추가 권한이 필요합니다.

```env
DISCORD_TOKEN=your_token_here
```

## `data/`

원신 캐릭터 및 보스 등의 데이터를 JSON 형식으로 저장합니다.

기본적인 데이터 구조 예시는 다음과 같습니다.

```json
 {
    "title": "Fischl",
    "ko_text": "피슬 에이미",
    "ko": "피슬",
    "weight": 1,
    "id": 32
  }
```

### 사용되는 데이터 항목

| 항목        | 설명                      |
| --------- | ----------------------- |
| `title`   | 원신 팬덤 위키 제목에 사용된 영어 이름 |
| `ko_text` | 위키에서 크롤링한 한글 데이터        |
| `ko`      | 수동으로 검수한 한국어 번역         |
| `weight`  | 랜덤 추첨 가중치               |

캐릭터 이름을 표시할 때는 항목이 존재하지 않는다면 다음 우선순위를 사용합니다.

```text
수동 번역(ko)
    ↓
크롤링된 한글 텍스트(ko_text)
    ↓
영어 이름(title)
```

# 🕷️ 데이터 크롤러

현재 데이터 크롤러와 번역 관련 스크립트는 `crawler.py`에 있습니다.

기존에 사용하던 테스트 및 예비 스크립트는 `test/`에 있습니다.

데이터 업데이트 과정에서 다음 사항을 고려해야합니다.

* 기존 캐릭터/보스 데이터 유지
* 수동 번역 유지
* 기존 가중치 유지
* 새로운 데이터 추가
* 삭제된 데이터 처리
* 중복 `pageid` 처리

업데이트 스크립트가 데이터를 갱신하더라도 기존에 사람이 직접 수정한 `ko`와 `weight`가 가능한 한 유지되도록 구성되어 있습니다.
